# Idea

Super App ช่วยงานเจ้าหน้าที่นิติวิทยาศาสตร์ ดังนี้

## 1. วิเคราะห์วัตถุพยานด้วย AI

ระบบจะแบ่งการวิเคราะห์ออกเป็น 2 Track หลัก:

### Track 1: อาวุธปืน (Firearms)

การวิเคราะห์อาวุธปืนจะดำเนินการเป็นขั้นตอน ดังนี้:

| Step | ขั้นตอน | ตัวอย่างผลลัพธ์ |
|------|---------|-----------------|
| 1 | ตรวจจับว่าเป็นอาวุธปืนหรือไม่ | Yes / No |
| 2 | ระบุกลไกของปืน | กึ่งอัตโนมัติ, ลูกโม่, ปืนพก, ปืนละออง |
| 3 | ระบุยี่ห้อ (Brand) | CZ, Glock, Beretta, Colt, Browning, SIG, Smith & Wesson, Walther, Kimber, Norinco |
| 4 | ระบุรุ่น (Model) | 75, 19, M9, GP100, etc. |

> **หมายเหตุ:** ระบบสามารถ Scale เพื่อเพิ่มการวิเคราะห์ประเภทอื่น ๆ ได้ในอนาคต เช่น ลายนิ้วมือ, DNA, เอกสารปลอม

### Track 2: ยาเสพติด (Narcotics) - อยู่ระหว่างการออกแบบ

> **รายละเอียดเพิ่มเติม:** กำลังพิจารณา
> - ตรวจจับว่าเป็นยาเสพติดหรือไม่
> - ระบุชนิด (ยาบ้า, ไอซ์, กัญชา, เฮโรอีน, โคเคน)
> - ประมาณน้ำหนัก/จำนวน

---

## 2. บันทึกประวัติการค้นพบวัตถุพยาน (Big Data)

ระบบจะบันทึกข้อมูลการค้นพบวัตถุพยานเพื่อสร้าง Big Data สำหรับการค้นหาความเชื่อมโยงในอนาคต

### ข้อมูลที่บันทึก (Data Fields)

| หมวด | รายละเอียด |
|------|------------|
| **ประเภทวัตถุพยาน** | อาวุธปืน / ยาเสพติด / (ประเภทอื่น ๆ ในอนาคต) |
| **ผู้ค้นพบ** | ชื่อเจ้าหน้าที่ที่ค้นพบ |
| **วันที่ค้นพบ** | ว/ด/ป |
| **เวลาที่ค้นพบ** | เวลา |
| **สถานที่ค้นพบ** | ตำบล, อำเภอ, จังหวัด, รหัสไปรษณีย์, ชื่อสถานที่ |
| **ข้อมูลเฉพาะ (อาวุธปืน)** | กลไก, ยี่ห้อ, รุ่น |
| **รูปภาพ** | ภาพที่เจ้าหน้าที่ถ่าย |

> **หมายเหตุ:** ในอนาคตสามารถเพิ่ม Data Fields ได้ตามความต้องการ

### ความเชื่อมโยง (Connections) ที่ต้องการหาในอนาคต

| ประเภทการเชื่อมโยง | รายละเอียด |
|---------------------|------------|
| **Link by Person** | ผู้ต้องหา/ผู้ค้นพบคนเดียวกัน |
| **Link by Location** | สถานที่ใกล้เคียงกัน |
| **Link by Time** | ช่วงเวลาใกล้เคียงกัน |
| **Link by Pattern** | ลักษณะเหมือนกัน (ยี่ห้อ/รุ่น/ชนิดยาเดียวกัน) |

## 3. Dashboard สำหรับแสดงผลสถิติและหา Insight

### Dashboard Statistics ที่แนะนำ

| Dashboard Type | Metrics |
|----------------|---------|
| **ทั่วไป** | จำนวนวัตถุพยานทั้งหมด, แยกตามประเภท (ปืน/ยา), Trend รายเดือน |
| **Firearms** | ยี่ห้อที่พบบ่อย, รุ่นที่พบบ่อย, กลไกที่พบบ่อย |
| **Narcotics** | ชนิดยาที่พบบ่อย, ปริมาณ, พื้นที่ที่พบบ่อย |
| **Geographic** | แผนที่แสดงการกระจายตัว (Heatmap), เรียงตาม จ./อ./ต. |
| **Temporal** | ช่วงเวลาที่พบบ่อย (เช้า/บ่าย/เย็น/ดึก) |

## 4. การแบ่ง User ตาม Role และ Permissions

ระบบมีการแบ่ง User ออกตาม Role ซึ่งแต่ละ Role จะมีสิทธิ์เข้าถึงการใช้งานที่แตกต่างกัน และจะใช้สิทธิ์ข้าม Role ไม่ได้โดยเด็ดขาด

### Roles

| Role | คำอธิบาย |
|------|----------|
| **เจ้าหน้าที่หน้างาน** | เจ้าหน้าที่ที่ปฏิบัติงานภาคสนาม |
| **เจ้าหน้าที่ Domain Expert** | ผู้เชี่ยวชาญเฉพาะทาง (ปืน หรือ ยาเสพติด) |
| **เจ้าหน้าที่ระดับสูงสุด** | ผู้บริหารระดับสูง |

---

### เจ้าหน้าที่หน้างาน (Field Officer)

| Permission | รายละเอียด |
|------------|------------|
| ถ่ายภาพวัตถุพยาน | ✓ |
| ส่งภาพให้ AI วิเคราะห์ | ✓ |
| บันทึกประวัติการค้นพบ | ✓ |
| ดูประวัติที่ตัวเองค้นพบ | ✓ (เฉพาะที่ตัวเองค้นพบ) |
| ดู Dashboard ของตัวเอง | ✓ (เฉพาะวัตถุพยานที่ตัวเองค้นพบ ทุกประเภท) |
| แสดงประวัติในรูปแบบแผนที่ | ✓ |
| ดูสารานุกรมวัตถุพยาน | ✓ |
| Export ออกเป็นรายงาน | ✓ |
| แชร์การค้นพบให้คนอื่น | ✓ |

---

### เจ้าหน้าที่ Domain Expert

| Permission | รายละเอียด |
|------------|------------|
| ถ่ายภาพวัตถุพยาน | ✓ |
| ส่งภาพให้ AI วิเคราะห์ | ✓ |
| บันทึกประวัติการค้นพบ | ✓ |
| ดูประวัติที่ตัวเองค้นพบ | ✓ |
| ดูประวัติใน Domain ที่เป็น Expert | ✓ (เฉพาะ Domain ตัวเอง) |
| ดู Dashboard ของ Domain ตัวเอง | ✓ (เฉพาะ Domain ตัวเอง - ไม่ข้าม Domain) |
| แสดงประวัติในรูปแบบแผนที่ | ✓ |
| ดูสารานุกรมวัตถุพยาน | ✓ |
| สร้างสารานุกรมวัตถุพยาน | ✓ |
| Export ออกเป็นรายงาน | ✓ |
| แชร์การค้นพบให้คนอื่น | ✓ |
| Label วัตถุพยาน Unknown | ✓ (กรณี AI ไม่สามารถระบุได้) |
| เพิ่ม Entity ใหม่ในระบบ | ✓ (กรณียังไม่มีในระบบ) |
| ใช้ภาพเป็น Big Data สำหรับ Train โมเดล | ✓ (อนาคต) |

> **หมายเหตุ:** Domain Expert จะเห็นข้อมูลเฉพาะ Domain ของตนเองเท่านั้น จะเห็นข้าม Domain ไม่ได้
> - Expert อาวุธปืน → เห็นเฉพาะอาวุธปืน
> - Expert ยาเสพติด → เห็นเฉพาะยาเสพติด

---

### เจ้าหน้าที่ระดับสูงสุด (Senior Officer)

| Permission | รายละเอียด |
|------------|------------|
| ถ่ายภาพวัตถุพยาน | ✓ |
| ส่งภาพให้ AI วิเคราะห์ | ✓ |
| บันทึกประวัติการค้นพบ | ✓ |
| ดูประวัติที่ตัวเองค้นพบ | ✓ |
| ดูประวัติวัตถุพยานทั้งหมด | ✓ (ทุก Domain ทุกประเภท) |
| ดู Dashboard ทั้งหมด | ✓ (เห็นทั้งหมด) |
| แสดงประวัติในรูปแบบแผนที่ | ✓ |
| ดูสารานุกรมวัตถุพยานทั้งหมด | ✓ |
| Export ออกเป็นรายงาน | ✓ |
| แชร์การค้นพบให้คนอื่น | ✓ |
| สร้าง Account ให้ User | ✓ |
| จัดการบัญชี User | ✓ |

## 5. การ Scale ในอนาคต

ระบบออกแบบให้รองรับการขยายตัวในอนาคต โดยสามารถเพิ่ม:

### Evidence Types ที่อาจเพิ่มในอนาคต

| ประเภท | คำอธิบาย |
|--------|----------|
| ลายนิ้วมือ (Fingerprint) | การตรวจจับและจับคู่ลายนิ้วมือ |
| DNA | การวิเคราะห์ DNA |
| เอกสารปลอม (Forged Documents) | การตรวจสอบเอกสารปลอม |
| Tool marks | รอยเครื่องมือบนวัตถุพยาน |

## สรุป

ระบบ Super App นี้ออกแบบมาเพื่อช่วยเหลือเจ้าหน้าที่นิติวิทยาศาสตร์ในการ:

1. **วิเคราะห์วัตถุพยาน** ด้วย AI อย่างรวดเร็วและแม่นยำ (Train เอง ไม่ใช้ API สำเร็จรูป เพื่อความ Private)
2. **สร้าง Big Data** เพื่อใช้ในการค้นหาความเชื่อมโยงในอนาคต
3. **แสดงผลสถิติ** ผ่าน Dashboard สำหรับผู้บริหาร
4. **ควบคุมสิทธิ์การเข้าถึง** ตาม Role อย่างเข้มงวด
5. **Scale ได้** เพื่อรองรับวัตถุพยานประเภทอื่น ๆ ในอนาคต
6. **รองรับหลาย User** พร้อมกัน
7. **Track ทุกการกระทำ** ด้วย Audit Trail

- ต้องการให้ AI วิเคราะห์อะไรบ้าง?
  - ตรวจจับว่าเป็นยาเสพติดหรือไม่?
  - ระบุชนิด? (ยาบ้า, ไอซ์, กัญชา, เฮโรอีน, โคเคน)
  - ประมาณน้ำหนัก/จำนวน?
  - ตรวจจับรูปร่างเม็ดยา (ถ้ามี)?

### 2. การ Export รายงาน
- รูปแบบรายงานที่ต้องการเป็นอะไร? (PDF, Excel, Word?)
- รายงานมีโครงสร้างอย่างไร?

### 3. การ Import Big Data เพื่อ Train โมเดล
- ต้องการให้ Domain Expert สามารถ Upload ข้อมูล Train เองได้เลย หรือต้องมี Admin อนุมัติก่อน?

### 4. Infrastructure ที่ต้องการ
- **Authentication:** Username/Password
- **Image Storage:** Cloud
- **Offline Mode:** ถ้าทำได้ดี แต่ไม่ได้ก็ไม่เป็นไร
- **Notification:** มีระบบ Notification
- **Audit Trail:** ต้องการ (Log การกระทำทุกอย่าง)
- **Data Retention:** ติดไว้ (ยังตอบไม่ชัด)
