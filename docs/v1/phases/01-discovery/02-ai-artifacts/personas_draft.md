## 2. Detailed Personas

### P1: สมชาย - เจ้าหน้าที่หน้างาน (Field Officer)

| Attribute | Description |
|-----------|-------------|
| **อายุ** | 25-40 ปี |
| **ตำแหน่ง** | เจ้าหน้าที่นิติวิทยาศาสตร์ ประจำจังหวัด |
| **ประสบการณ์** | 1-5 ปี |
| **ทักษะเทคโนโลยี** | ปานกลาง - ใช้งานมือถือได้ |

#### Goals & Motivations

- ต้องการวิเคราะห์วัตถุพยานได้รวดเร็ว
- ต้องการบันทึกประวัติการค้นพบสะดวก
- ต้องการดูประวัติที่ตัวเองค้นพบได้
- ต้องการ Export รายงานได้

#### Pain Points

- ต้องวิเคราะห์ด้วยตาวางละเอียด ใช้เวลานาน
- ไม่สามารถหาความเชื่อมโยงกับคดีอื่นได้
- ต้องรวบรวมข้อมูลเอง

#### Permissions

| Action | Access |
|--------|--------|
| ถ่ายภาพวัตถุพยาน | ✓ |
| ส่งภาพให้ AI วิเคราะห์ | ✓ |
| บันทึกประวัติการค้นพบ | ✓ |
| ดูประวัติที่ตัวเองค้นพบ | ✓ |
| ดู Dashboard ของตัวเอง | ✓ |
| แสดงประวัติในรูปแบบแผนที่ | ✓ |
| ดูสารานุกรมวัตถุพยาน | ✓ |
| Export ออกเป็นรายงาน | ✓ |
| แชร์การค้นพบให้คนอื่น | ✓ |

### P2: สมศักดิ์ - Domain Expert (อาวุธปืน)

| Attribute | Description |
|-----------|-------------|
| **อายุ** | 35-50 ปี |
| **ตำแหน่ง** | นักนิติวิทยาศาสตร์ ผู้เชี่ยวชาญด้านอาวุธปืน |
| **ประสบการณ์** | 10+ ปี |
| **ทักษะเทคโลยี** | สูง - ใช้งานระบบได้ |

#### Goals & Motivations

- ต้องการตรวจสอบความถูกต้องของการวิเคราะห์
- ต้องการ Label วัตถุพยานที่ AI ไม่รู้จัก
- ต้องการเพิ่มยี่ห้อ/รุ่นใหม่ในระบบ
- ต้องการใช้ข้อมูล Train โมเดล

#### Pain Points

- AI อาจจำแนกผิดได้
- ต้องการปรับปรุงโมเดลให้แม่นยำขึ้น

#### Permissions

| Action | Access |
|--------|--------|
| ถ่ายภาพวัตถุพยาน | ✓ |
| ส่งภาพให้ AI วิเคราะห์ | ✓ |
| บันทึกประวัติการค้นพบ | ✓ |
| ดูประวัติที่ตัวเองค้นพบ | ✓ |
| ดูประวัติใน Domain ปืน | ✓ |
| ดู Dashboard ของ Domain ปืน | ✓ |
| แสดงประวัติในรูปแบบแผนที่ | ✓ |
| ดูสารานุกรมวัตถุพยาน | ✓ |
| สร้างสารานุกรมวัตถุพยาน | ✓ |
| Export ออกเป็นรายงาน | ✓ |
| แชร์การค้นพบให้คนอื่น | ✓ |
| Label วัตถุพยาน Unknown | ✓ |
| เพิ่ม Entity ใหม่ในระบบ | ✓ |
| ใช้ภาพเป็น Big Data Train โมเดล | ✓ |

> **หมายเหตุ:** P2 จะเห็นเฉพาะข้อมูลอาวุธปืน จะเห็นข้อมูลยาเสพติดไม่ได้
